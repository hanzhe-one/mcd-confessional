麦门告解室

四角色消费审判庭 · 取数交给 MCP，算术交给代码，表达交给 Agent

不是卡路里计算器，是审计。

把每一笔历史订单丢进券组合优化器重算一遍，算出你「本该花多少」， 差额归因到「没用券 / 券没用到位 / 规格不划算」。

然后四个角色开庭：审计官摆数字、辩护律师找减刑、告解师定罪、 执事下达每日 60 分钟的赎罪计划并盯着你打卡。

查看源码 单独打开证书

四个角色，分工是咬合的

THE AUDITOR
审计官
「感情归你，数字归我。」逐单核价，把亏损摆上台面。
THE ADVOCATE
辩护律师
「没有人天生就是罪人。」从真实数据找减刑情节，每条减刑 5%，会被驳回。
THE CONFESSOR
告解师
「本席不同情你，但本席理解你。」盘问异常订单、定罪、写批注。
THE BAILIFF
执事
「判决书签了字，就得走完这段路。」入账、下达计划、盯打卡、券预警。

真实庭审输出（摘要）

【审计官陈词】
经逐单复核：按当前券池的最优组合，7 单里有 3 单本可以更便宜。
实付合计 333.00 元，理论最优合计 311.50 元，差额 36.00 元（占实付 10.8%）。
亏损最重的一单：实付 122.00 元，最优价 100.00 元，白扔 22.00 元。

【合议量刑】
基准刑：热量赎罪 约 1.2 天 + 亏损罚金赎罪 约 6.0 小时
采纳辩护 4 条，减刑 20%　驳回 2 条，理由：证据不足或属普遍行为
最终赎罪义务：约 1.1 天

【执事登记】
赎罪计划：每日步行 60 分钟，预计 27 天完成。
组合优化：位掩码 DP 自测：15 项通过（含 200 例暴力对拍） 模型不参与任何金额计算

零配置体验

git clone https://github.com/hanzhe-one/mcd-confessional.git
cd mcd-confessional
python -m src.cli trial --save    # 开庭（虚构档案，无需 Token）
python -m src.cli checkin -m 60   # 打卡赎罪 60 分钟
python -m src.selftest            # 跑自测
本项目为比赛参赛作品，由开发者独立开发，非麦当劳官方产品。
