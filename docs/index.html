麦门告解室

四角色消费审判庭 · 取数交给 MCP，算术交给代码，表达交给 Agent

不是卡路里计算器，是审计。

把每一笔历史订单丢进券组合优化器重算一遍，算出你「本该花多少」， 差额归因到「没用券 / 券没用到位 / 规格不划算」。

然后四个角色开庭：审计官摆数字、辩护律师找减刑、告解师定罪、 执事下达每日 60 分钟的赎罪计划并盯着你打卡。

查看源码 完整庭审记录 告解证书

四个角色，分工是咬合的

THE AUDITOR
审计官
「感情归你，数字归我。」逐单核价，把亏损摆上台面。
THE ADVOCATE
辩护律师
「没有人天生就是罪人。」从真实数据找减刑情节，每条减刑 5%，会被驳回。
THE CONFESSOR
告解师
「本席不同情你，但本席理解你。」盘问异常订单、定罪、写批注。
THE BAILIFF
执事
「判决书签了字，就得走完这段路。」入账、下达计划、盯打卡、券预警。
