麦门告解室

“孩子，坐。让本席看看你这一年都在麦当劳犯了些什么事。”

不是卡路里计算器，是审判。

拉取你的麦当劳历史订单，按热量与量刑规则逐单判罪：深夜下单罪加一等、单人过百暴食罪、同款三件起算贪、选无糖将功补过。

累计罪恶点判定罪级，换算步行赎罪工时；卡包里真实的优惠券可作为官方赦免抵扣工时——券过期，赦免失效。

查看源码 单独打开证书

玩法机制

⚖️ 罪律引擎
罪恶点 = 千卡 × 0.1；深夜 ×2、周五 ×1.2、暴食 ×1.5、贪 ×1.3、无糖 ×0.9
🏛️ 四阶罪级
白衣罪徒 → 黑袍常客 → 麦门叛徒 → 逐出麦籍（死罪）
🚶 赎罪工时
千卡 × 3 分钟步行，精确到“你还欠麦当劳多少路”
🎫 真实赦免
MCP 读取卡包真实优惠券，每张抵 5% 工时（上限 40%），过期即失效

零安装体验

git clone https://github.com/hanzhe-one/mcd-confessional.git
cd mcd-confessional
python -m src.cli demo          # 内置虚构档案，无需 Token
python -m src.cli confess       # 接入 MCP，对真实订单宣判

输出：examples/sin-report.md（完整罪状报告）+ examples/confession-certificate.html（本文所示的证书）
