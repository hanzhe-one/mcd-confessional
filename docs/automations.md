# 主动提醒：三个定时任务

Agent 和工具的分水岭在于**它会不会在没人叫的时候找你**。麦门告解室配套三个定时任务，
可直接在 WorkBuddy 的自动化（Automation）里按下面的文案创建。

> 前提：已安装本 Skill 并配置麦当劳 MCP（`MCD_MCP_TOKEN`）。

---

## 1. 晚祷 · 每晚 22:00

**调度**：每天 22:00

**Prompt**：

```
检查我的麦当劳罪恶账本（读 data/ledger.json，用 Ledger.load 计算 summary）。
然后以「麦门告解室执事」的口吻做晚祷提醒：
1. 当前尚欠赎罪 X 分钟，连续打卡 Y 天，赎罪进度 Z%；
2. 若今晚是周五或已过 22 点，提醒「深夜下单罪加一等（×2）」；
3. 若我有 24 小时内到期的优惠券（调用 query-my-coupons），报成「赦免凭证将于 X 小时后失效」；
4. 最后问一句：今夜还要下单吗？
只输出 4 行以内，不要长篇大论。
```

**为什么有效**：常规优惠券推送是骚扰，「你的赎罪还剩 X 分钟」是叙事。同一件事，不同的说法。

---

## 2. 券预警 · 每天 10:00

**调度**：每天 10:00

**Prompt**：

```
调用麦当劳 MCP 的 query-my-coupons 获取我卡包里的券，筛出未来 24 小时内到期的。
以「赦免凭证即将失效」的说法提醒我：列出券名、到期时间、剩余小时数。
若没有 24 小时内到期的券，只回一句「今日无凭证失效」。
```

---

## 3. 结案陈词 · 每周日 21:00

**调度**：每周日 21:00

**Prompt**：

```
读取我的麦当劳罪恶账本（data/ledger.json），汇总本周新增案件与赎罪进度。
以「麦门告解室告解师」的口吻出一份结案陈词，包含：
1. 本周新增几案、新增亏损多少元、新增赎罪工时；
2. 本周赎罪完成度，连续打卡天数；
3. 一句判词（不超过 40 字，毒舌但不要羞辱）；
4. 下周的一条具体建议（必须是可执行的，例如「周三的券在周五会过期，别等到周五」）。
```

---

## 实现说明

这三个任务本质上只做两件事：**读账本 + 调 MCP**，没有复杂的推理需求，
所以即使用最基础的模型也不会跑偏——这正是把「确定性计算」和「叙事表达」分开的好处：

| 层 | 谁负责 | 特点 |
| --- | --- | --- |
| 数字 | `src/audit.py` / `src/optimizer.py` / `src/state.py` | 确定性、可测试、可复现 |
| 叙事 | Agent 的 prompt | 灵活、有性格、可调整 |

模型只负责「怎么说」，不负责「算多少」。
